# Wesley Tiago — Portfólio

Meu portfólio em HTML, CSS e JavaScript, com uma evolução visual em três níveis: **Simples → Intermediário → Avançado**.

## Acessar

[wesleyttiago.github.io](https://wesleyttiago.github.io/)

## Conteúdo

- Apresentação e trajetória entre suporte em TI e desenvolvimento.
- Projetos públicos do GitHub com demonstrações e links para o código.
- Filtros por tema e detalhes dos projetos.
- Layout responsivo, navegação por teclado e preferência por movimento reduzido.
- Contatos pelo GitHub e LinkedIn.

## Arquivos

| Arquivo | Função |
| --- | --- |
| `index.html` | Estrutura semântica e conteúdo |
| `style.css` | Estilos e layout responsivo |
| `script.js` | Filtros, detalhes e indicador de navegação |
| `assets/` | Capturas dos projetos apresentados |
| `.nojekyll` | Publicação estática no GitHub Pages |

Não há etapa de compilação ou dependências para instalar. Abra `index.html` no navegador para visualizar localmente. As fontes externas são opcionais e possuem alternativas locais.

## Publicação

GitHub Pages publica a branch `main`, diretório raiz (`/`). Alterações nesses arquivos são publicadas automaticamente após o processamento do Pages.

Os projetos apresentados são estudos; não representam serviços completos de produção.
